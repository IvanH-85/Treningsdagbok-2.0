# Treningsdagbok 2.0

En enkel mobiltilpasset treningsdagbok for Espen og Ivan.

## Innhold
- Økt 1 – Styrke 1 med vekt/reps og progresjon
- Økt 2 – frivillig jogg/gåtur
- Økt 3 – Styrke 2 som 4 runder på tid med rundetider og totaltid
- Økt 4 – fjelltur/rolig løpetur
- Lokal lagring i nettleseren
- Eksport/import av sikkerhetskopi

## GitHub Pages
Publiser fra `main`-branch og `/ (root)`.

Dette repoet er kun for treningsdagboken og er adskilt fra Medvirk.
